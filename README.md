# 林办档案馆 · Archive of Lin Biao

一个整理林彪及相关人物、历史事件、军事史和文化资料的非营利文献目录。包含公开的书目检索页面、本机编目后台，以及由 Proton Drive 自动更新目录的同步程序。

仓库：<https://github.com/linyurong913/ArchiveOfLin>

本项目仅供学术交流与研究。收录、引用或链接的内容不代表网站创作者、维护者或支持者的政治立场。版权、纠错或其他权益问题，请联系 **linyurong@proton.me**，提供条目和相关说明，以便核查、更正或移除。

## 功能

- 分类和文件格式筛选，按目录顺序、书名、最近编目排序，导出当前书目为 CSV。
- 文献详情展示编号、作者、原文件名、定位路径、版本及编目依据；支持复制文件名和条目链接。
- 文献窗口提供共享文库密码提示：**抗大校训八个字的拼音首字母，全小写**。不保存密码明文。
- 书法 SVG 标识，中英文馆名对齐，不同文件格式使用独立配色，适配移动屏幕。
- 管理员可新增、编辑、发布、归档书目，查看修订历史，上传文件版本及导出书目备份。
- 支持创作者、免责声明和版权联系入口。
- 导出纯静态的只读网站，不包含后台和私有运行数据。

## 技术结构

原生 HTML、CSS、JavaScript + Node.js HTTP 服务 + Node 内置 SQLite。没有 npm 第三方运行依赖、外部字体、前端 CDN 或统计脚本。

```text
ArchiveOfLin/
├─ public/                 # 读者页面、管理员登录和管理界面
├─ data/seed.json          # 初始公开书目
├─ db.mjs                  # SQLite 数据与修订记录
├─ auth.mjs                # 管理员认证和会话
├─ server.mjs              # 本机 HTTP 服务与 API
├─ scripts/
│  ├─ export.mjs           # 静态网站导出
│  ├─ reset-admin-key.mjs  # 管理员密钥重置
│  └─ *.test.mjs           # 权限及馆藏功能测试
├─ Start.ps1               # Windows 启动脚本
└─ dist/                   # 导出后生成，不纳入 Git
```

## 本机运行

需要 **Node.js 24 或更新版本**与 Git。

```sh
git clone https://github.com/linyurong913/ArchiveOfLin.git
cd ArchiveOfLin
node server.mjs
```

无需运行 `npm install`。Windows 也可运行 `Start.ps1`；如果脚本执行策略不允许，直接使用 Node 命令即可。

- 读者目录：<http://127.0.0.1:8787/>
- 管理员后台：<http://127.0.0.1:8787/admin>

服务仅绑定 `127.0.0.1`，关闭进程会停止访问。更换端口的 PowerShell 示例：

```powershell
$env:PORT = '8788'
node server.mjs
```

## 管理员登录

1. 首次启动自动生成管理员密钥，在本机打开 `data/admin-access-key.txt` 获取。
2. 从顶部“管理员后台”或 `/admin` 登录。不需要用户名，此密钥与 Proton 分享密码无关。
3. 登录有效期为 8 小时，支持主动退出；重启服务会使所有现有会话失效。
4. 更换或找回密钥时，在项目目录运行：

```sh
node scripts/reset-admin-key.mjs
```

新密钥写入同一本机文件，旧密钥和旧会话立即失效，无需重启。

所有管理 API 均检查会话，未登录不能读取草稿、修改书目或上传文件。写操作另校验 Origin 和会话令牌。Cookie 使用 HttpOnly、SameSite=Strict；本机 HTTP 未设置需要 HTTPS 的 Secure 属性。15 分钟内连续失败 8 次会暂停该时间窗口内的登录尝试。

认证配置保存高熵随机密钥的 SHA-256 摘要，登录用的密钥文件由维护者在本机保管；密钥不进入网页代码、localStorage、Git 或静态导出。拥有同一操作系统账户或项目文件读取权限的人仍可能读取密钥或数据库，网页登录不能隔离操作系统账户。

当前采用 **GitHub Pages 公开目录 + 本机 Proton 同步程序 + 本机编目后台**。配置、运行条件、故障处理和编号规则见 [PROTON-SYNC.md](PROTON-SYNC.md)。若以后需要公网远程管理，应另行配置 HTTPS、可靠的身份验证与多因素认证、权限、审计和备份，不能仅改绑 `0.0.0.0` 就开放本服务。

## 编目与文件版本

1. 新增书目并保存为草稿，补充作者、分类和来源信息；未知年代留空。
2. 保存后可上传 PDF、TXT、EPUB、ZIP、DOCX，单个文件最大 512 MB。
3. 上传文件保存在本机 `storage/`；同一书目按 SHA-256 检查重复，不同版本保留。
4. 发布后条目进入读者目录；下载入口只使用核实的 Proton 单文件链接。归档后停止展示，但不会删除 Proton 文件或改变其分享权限。

文献下载统一跳转至 Proton Drive。网站不再展示本机文件阅读/下载入口，`/files/` 路由也不再提供原件；既有本机文件仍保留，不会被删除。静态导出只包含书目及 Proton 原文入口。

官方 CLI 授权后，同步程序为指定文库范围内的文件创建独立、只读、带密码的分享链接。文件夹入口不能冒充单文件链接；未同步完成的条目不提供下载按钮。同步程序仅发布书目信息及分享 URL，不向 GitHub 上传原件或分享密码。

现有 `LB-00001` 至 `LB-00028` 按初始导入顺序分配，不表示年代或分类；手动新增为 `LB-` 加随机短标识，Proton 自动导入为 `LB-P` 加文件 UID 的 SHA-256 前 16 位。重新分组不会改变已有编号。

`data/seed.json` 仅用于首次初始化。修改 seed 不会覆盖现有数据库，已运行的馆藏请在后台编辑。Git 管理代码和 seed；书目修订历史保存在 SQLite 中，目前没有一键回滚界面。

## 导出公开静态网站

```sh
node scripts/export.mjs
```

生成的 `dist/` 包含 HTML、CSS、JavaScript、SVG 和 `catalog.json`，只导出已发布书目。**不包含管理页、登录页、认证文件、SQLite 数据库、本机上传文件或密码明文。**

部署时只上传 `dist/` 的内容，可用于 GitHub Pages 或其他静态托管。`scripts/publish-pages.mjs` 发布到 `gh-pages` 分支；首次需启用仓库的 Pages 托管。静态服务不运行 Node 后台，在公网访问时也不显示管理员入口。

修改前端或书目后需要重新导出和部署，自动任务会执行这些步骤。导出包含共享文库地址与密码提示；提示本身不是身份验证机制。网站更新取决于同步任务和 Pages 构建成功，第三方缓存不由本站控制。

## 数据与备份

| 文件／目录 | 用途 | Git／公开导出 |
| --- | --- | --- |
| `data/seed.json` | 初始公开书目与共享文库地址 | Git；发布条目可导出 |
| `data/library.sqlite*` | 实际馆藏、修订历史、同步任务 | 排除 |
| `data/admin-auth.json` | 管理员密钥摘要 | 排除 |
| `data/admin-access-key.txt` | 本机管理员登录密钥 | 排除 |
| `data/proton-sync/` | Proton 文件关联、同步锁、最近任务日志 | 排除 |
| `storage/` | 本机上传文件 | 排除，仅 `.gitkeep` 纳入 Git |
| `.env*`、`*.log` | 私有配置和日志 | 排除 |

完整备份前先停止服务，私下保存数据库、文件存储及需要的认证文件。管理页“导出书目备份”只有书目和文件元信息，**不包含文献文件、完整修订历史或一键恢复能力**。

共享链接、加密存储和匿名署名不能保证不可追溯。不要提交个人凭据，也不要把整个运行目录当作静态网站公开上传。

## 已知限制与后续方向

- 同步以文件为单位，ZIP 内部与文集中单篇未逐一编目，不能称为全文检索。
- 题名和作者主要来自文件名，须继续核对版权页、目录、版本与正文。
- 下载和密码验证在 Proton 完成，本站不提供原件，也不保证 Proton 对所有文件格式提供在线预览。
- 本机需开机、登录且联网，授权失效或网络故障会延迟更新；不会把失败扫描当作空目录发布。
- 不提供原件双向同步；从网站上传的本机文件不会进入 Proton。
- 后续按“资料类型 + 人物／事件／部队标签 + 专题”完善分类，建立作品、版本与文件关系，再扩充正文索引。
