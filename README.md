# 林办档案馆 · 初版

一个不依赖外部前端库、外部字体或统计脚本的文献目录。包含可搜索的读者页面，以及只在本机运行的 SQLite 管理后台。

## 已完成

- 根据实际浏览的 Proton 共享目录导入 28 份书目，按维护者选择展示 14 个分类。
- 按书名、作者、原始文件名、来源路径搜索；格式和分类筛选；书名、最近编目排序。
- 文献详情、固定条目编号、带编号的页面链接、CSV 书目导出。
- 本机编辑、新增、草稿／发布／归档状态；每次保存记录书目快照。
- 本机文件上传、SHA-256 查重、保留多个文件版本。PDF/TXT 可在浏览器中打开，其余格式下载。
- 公共静态目录导出。静态包不含管理页、SQLite 数据库、本机文件或密码。

- 新增“支持创作者”区，提供联系邮箱与支持、打赏赞助说明。

## 已知边界

本次是首批书目，不是全库完整递归抓取。已浏览的分类是传记、913相关史学、林言林语、相关亲历者叙述、军事史目录，另收录根目录的一份 EPUB。其余分类保留原名称，明确标记待编目。文件夹未显示的内容、嵌套内容及文件正文未完整检查。

标题和作者主要从文件名整理，年代留空；没有声称核对原书版权页或资料史实。部分文件名中的出版社署名仍需进一步核实其著者角色。

目前各条目链接进入用户提供的同一个 Proton 共享文库，需按详情中的目录路径定位。尚未获取经过验证的逐文件分享链接。后台可补充单文件链接并选择“已核实的单文件分享链接”。没有使用推测的下载地址或将共享页面伪装成 PDF 直链。

共享文件夹密码仅用于本次浏览，没有写入任何网站文件。读者仍需在 Proton 页面自行输入密码。共享链接不等于匿名，本站也不承诺不可追溯。

**Proton 自动上传、自动回读和双向同步尚未接通。** 本机上传成功不代表 Proton 上传成功；同步任务明确保存为 `not_connected`。当前共享链接只用于访问，不能代替账户级同步授权。不要在网页代码中填写 Proton 账户密码。后续应在本机登录官方 Proton CLI，验证当前 CLI 的上传、列举、下载、冲突处理与分享能力后再实现同步适配器。

当前没有公网部署。`127.0.0.1` 链接只在运行服务的电脑上可用。

## 启动

需要 Node.js 24 或更新版本。本项目无 npm 第三方依赖，无需 `npm install`。

在项目目录中运行：

```powershell
node server.mjs
```

也可以在 PowerShell 中运行 `./Start.ps1`。若系统脚本策略限制执行，可直接运行上方 Node 命令，无需修改系统策略。

- 读者目录：<http://127.0.0.1:8787>
- 本机管理：<http://127.0.0.1:8787/admin>

`Start.ps1` 会优先寻找系统 Node，也兼容本机已有的 Codex 配套 Node 路径。关闭运行窗口会停止服务。端口已占用时可先设置 `$env:PORT='8788'`，再运行 `node server.mjs`。

服务只绑定 `127.0.0.1`，校验 Host、管理写入 Origin 与会话令牌。它是单人本机后台，**不是可直接暴露到公网的多用户后台**。勿直接改绑到 `0.0.0.0`。

## 管理与版本

1. 打开管理页，点击“新增书目”，填写必要字段，默认为草稿。
2. 保存后可以上传文件，单个文件最多 512 MB。文件保存在 `storage/`。
3. 检查书目和文件后选择“已发布”并保存，读者目录即可看到。
4. 归档条目会从本机读者目录移除，对应本机文件也停止提供；不会删除文件或改变 Proton 的原有分享。
5. 编辑和上传会新增修订记录，旧文件不会被覆盖。初版提供历史查看，尚无一键回滚按钮。

若需要整站备份，先停止服务，再复制整个项目目录，特别是 `data/` 和 `storage/`。管理页的“导出书目备份”仅导出书目与文件元信息，**不包含原文件、完整修订历史或一键恢复功能**。

## 数据结构

| 表 | 内容 |
|---|---|
| `items` | 书目、固定 ID、来源路径、分享链接、发布状态 |
| `categories` | 分类与编目覆盖状态 |
| `files` | 不可变的本机文件版本、大小、校验值 |
| `revisions` | 每次保存的书目 JSON 快照 |
| `sync_jobs` | 尚未连接的同步任务与真实状态 |
| `meta` | 共享目录名称、来源链接、目录快照日期 |

实际数据库是 `data/library.sqlite`。首次启动由 `data/seed.json` 初始化，后续启动不会覆盖已有数据。不要直接修改 seed 期待覆盖已运行的数据库；使用管理页保存。

## 导出免费托管所需的静态目录

```powershell
node scripts/export.mjs
```

将生成的 `dist/` 内容交给支持静态网站的托管平台即可。只有已发布书目会导出，不包含本机文件版本，Proton 原文入口保留。导出过程不自行创建托管账户或上传任何文件。

以后每次修改书目后需要重新导出和重新部署。托管平台的历史部署及缓存不受本机归档操作控制。分享公开链接前先检查 Proton 页面显示的账号信息。

代码、seed、前端可用 Git 管理；SQLite 和上传文件已在 `.gitignore` 中排除，需要单独备份。静态导出不包含 `.git` 历史。
